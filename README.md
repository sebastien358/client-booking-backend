# client-booking-backend

## Compte de démonstration pour les recruteurs

## Objectif du projet

Ce projet démontre la maîtrise des concepts de **gestion de réservation**, notamment :
- Authentification sécurisée JWT avec gestion des rôles (admin / client)
- Système de prise de rendez-vous intégré (sélection de service, praticien, créneau disponible)
- Gestion des rendez-vous (création, modification, suppression)
- Système de réservation avec logique métier (disponibilités, planification)
- Back-office administrateur complet (utilisateurs, services, messages, témoignages)
- API REST Symfony structurée
- State management avec Pinia et persistance des données
